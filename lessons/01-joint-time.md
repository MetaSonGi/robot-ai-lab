# 1. 관절 속도로 이동 시간 계산하기

## 1-1. 가장 단순한 식

관절 하나가 일정한 속도로 움직인다면

```
시간(초) = 이동각도(°) / 회전속도(°/s)
90° / 30°/s = 3초
```

## 1-2. 실제 모터는 가속·감속을 한다 (사다리꼴 프로파일)

모터는 순간적으로 최고속도에 도달할 수 없습니다. 속도 그래프가 사다리꼴 모양이 됩니다.

```
속도
 ▲     ┌──────────┐  ← 최고속도 v
 │    /            \
 │   /              \
 └──┴────────────────┴──▶ 시간
    가속    등속     감속
```

- 가속·감속에 쓰는 각도 합 = `v² / a`
- 이동각도 ≥ `v² / a` → **사다리꼴**:  `T = 각도/v + v/a`
- 이동각도 < `v² / a` → **삼각형**(최고속도 못 찍음):  `T = 2·√(각도/a)`

예: 90°, v=30°/s, a=60°/s² → 90/30 + 30/60 = **3.5초** (단순식보다 0.5초 김)

## 1-3. 관절 6개가 동시에 움직이면

로봇은 모든 관절이 **같이 도착**하도록 맞춥니다. 그래서 구간 시간은 **가장 오래 걸리는 관절**의 시간입니다.

```python
segment_time = max(관절1시간, 관절2시간, ..., 관절6시간)
```

## 1-4. 물건 옮기기 전체 시간

```
전체 = Σ(이동 구간 시간) + 집기 시간 + 놓기 시간
```

티칭 포즈 예: 홈 → 물건 위 → 집기 → 들기 → 목표 위 → 놓기 → 홈 (6구간)

## 1-5. 티칭할 때 기록할 데이터

| 데이터 | 이유 |
|---|---|
| 구간별 시작·목표 관절각 | 얼마나 움직이는지 |
| 관절별 속도·가속도 설정 | 시간 계산 |
| 실제 관절각 + 타임스탬프 | 명령과 실제 차이 |
| 물건 무게, 그리퍼 시간 | 부가 시간 |
| 전체 시간, 성공 여부 | 평가·최적화 |
