# 2. AI(지도학습)로 예측 오차 줄이기

## 왜 이론값이 틀릴까

계산식은 이상적인 로봇을 가정합니다. 실제로는

- 무거운 물건 → 가속이 덜 됨
- 빠르게 멈추면 → 진동이 멈출 때까지 기다림(정착 시간)
- 제어기·통신 지연, 측정 잡음

## 아이디어: 계산 + 학습

```
이론 시간(물리 계산) ─┐
속도, 무게, 각도     ─┼─▶ [회귀 모델] ─▶ 실제 시간 예측
```

물리 계산을 버리지 않고 **입력 특징으로 넣는 것**이 핵심입니다. 데이터가 적어도 잘 맞습니다.

## 결과 (가상 데이터 600개)

| 방법 | 평균 오차 |
|---|---|
| 이론값 그대로 | 1.28초 |
| 선형회귀 보정 | **0.11초** |
| 랜덤포레스트 | 0.19초 |

선형회귀가 더 좋은 이유: 이 데이터의 오차가 `속도²`, `이론시간×무게×속도` 처럼 **특징으로 잘 표현되는 형태**이기 때문입니다. 좋은 특징을 만들면 단순한 모델로도 충분합니다(특징 공학).

## 용어

- **MAE(평균 절대 오차)**: |예측 − 실제| 의 평균. 단위가 초라서 이해하기 쉬움
- **train/test 분리**: 학습에 안 쓴 데이터로 평가해야 진짜 실력
- **과적합**: 학습 데이터만 외워서 새 데이터에 약해지는 현상
