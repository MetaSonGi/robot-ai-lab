# 3. 강화학습으로 속도 최적화

## 문제

빠르게 옮기면 시간은 줄지만 물건을 떨어뜨릴 수 있습니다. 무게에 따라 **가장 좋은 속도**는 다릅니다. 이걸 로봇이 직접 시도하며 배우게 합니다.

## 구성 요소

| 요소 | 이 예제에서 |
|---|---|
| 상태 (state) | 물건 무게 구간: 가벼움 / 보통 / 무거움 |
| 행동 (action) | 속도 30·50·70·90% |
| 보상 (reward) | −작업시간, 떨어뜨리면 −10 추가 |
| 정책 (policy) | 상태마다 Q값이 가장 큰 행동 선택 |

## Q-러닝 한 줄 요약

```
Q[상태][행동] ← Q + α × (받은 보상 − Q)
```

- **α (학습률)**: 새 경험을 얼마나 반영할지
- **ε (탐험률)**: 가끔 무작위 행동을 해서 더 좋은 선택이 있는지 확인

## 결과

```
                30%     50%     70%     90%
가벼움        -9.16   -7.77   -7.31★  -7.96
보통          -9.77   -8.58★  -9.36  -11.31
무거움       -11.22  -10.05★ -10.83  -13.77
```

→ 가벼우면 빠르게(70%), 무거우면 천천히(50%). 사람이 규칙을 정하지 않았는데 스스로 찾았습니다.

## 실제 로봇에서는

1. 실제 로봇으로 수천 번 시도하면 위험하고 오래 걸림
2. 그래서 **시뮬레이터**(MuJoCo, Isaac Sim, Gazebo)에서 학습
3. 학습한 정책을 실제 로봇에 옮김 (Sim-to-Real)
4. 행동이 연속값(관절 토크 등)이면 PPO, SAC 같은 심층 강화학습 사용
