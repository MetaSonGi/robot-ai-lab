# 4. VLA: 보고, 듣고, 움직이는 로봇

**VLA = Vision-Language-Action**

```
카메라 영상  ─┐
"빨간 컵을   ─┼─▶ [VLA 모델] ─▶ 로봇 행동 (관절 목표 / 그리퍼 열고닫기)
 상자에 넣어" ─┘
```

## 지금까지 만든 것과의 관계

| 역할 | 담당 |
|---|---|
| 무엇을, 어디로 옮길지 결정 | VLA |
| 그 동작이 몇 초 걸릴지 예측 | 이 저장소의 시간 예측 모델 |
| 몇 % 속도로 할지 | 강화학습 정책 |

VLA 가 만든 동작 계획을 시간 예측기에 넣으면 "이 명령은 약 7초 걸립니다" 처럼 알려주는 시스템을 만들 수 있습니다.

## 배우는 순서

1. **모방학습(Behavior Cloning)**: 사람이 티칭한 동작(관찰→행동 쌍)을 그대로 따라 하도록 학습
2. **이미지 인식**: 카메라로 물건 위치 찾기 (OpenCV → 딥러닝 검출)
3. **언어 조건**: 명령 문장에 따라 다른 행동
4. 공개 VLA 모델(예: OpenVLA, π0 계열, LeRobot 프로젝트)을 시뮬레이터에서 실행해 보기
