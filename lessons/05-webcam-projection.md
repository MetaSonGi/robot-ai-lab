# 5. 웹캠 + 빔프로젝터 인터랙티브 미디어아트

## 작품: 손으로 벽에 빛 그리기

```
웹캠 촬영 → 손/움직임 위치 → 좌표 변환(호모그래피) → 빛 궤적 → 빔프로젝터 투사
```

## 준비물

- 일반 USB 웹캠 1대
- 빔프로젝터 (노트북 보조 모니터로 연결)
- 흰 벽 또는 스크린, 어두운 방

웹캠은 프로젝터 화면 전체가 보이도록 프로젝터 근처에 고정합니다.

## 5-1. 움직임 추적 (OpenCV 기초)

```
컬러 → 흑백 → 블러(잡음 제거) → 이전 프레임과 차이 → 이진화 → 흰 영역의 중심
```

`cv2.moments` 로 흰 픽셀들의 무게중심을 구하면 그게 '움직이는 손의 위치'입니다.

mediapipe 가 설치돼 있으면 검지 끝을 정확히 추적합니다 (`m` 키로 전환).

## 5-2. 좌표 맞추기: 호모그래피

카메라가 비스듬히 벽을 보기 때문에 카메라 좌표 ≠ 프로젝터 좌표입니다.
**평평한 벽**이라면 3×3 행렬 하나(H)로 변환할 수 있습니다.

```python
H = cv2.getPerspectiveTransform(카메라에서_본_4점, 프로젝터_4점)
프로젝터좌표 = cv2.perspectiveTransform(카메라좌표, H)
```

`calibrate.py` 가 프로젝터에 4개 원을 띄우고, 카메라 화면에서 그 원을 클릭하면 H 를 저장합니다.

> 입체 물체 표면에 정확히 맞추려면 구조광(그레이코드 패턴) 등 3D 복원이 필요합니다. 호모그래피는 평면 전용.

## 5-3. 빛 효과

- 매 프레임 캔버스에 0.96 을 곱함 → 잔상이 서서히 사라짐
- 가우시안 블러를 더함 → 빛 번짐(glow)
- 시간에 따라 색상(hue) 변화 → 무지개 궤적

## 실행

```bash
python mediaart/calibrate.py --px 1920   # 프로젝터가 주 모니터 오른쪽에 있을 때
python mediaart/draw_light.py
```
