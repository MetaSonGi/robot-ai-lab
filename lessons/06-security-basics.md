# 6. 로봇·카메라 시스템 보안 기초

보안(해킹) 공부는 **내가 소유한 장비, 직접 만든 실습 환경**에서만 합니다. 남의 시스템을 허락 없이 점검하는 것은 불법입니다.

## 이 프로젝트에서 공격받을 수 있는 곳

| 위치 | 위험 | 기본 대책 |
|---|---|---|
| 로봇 제어 PC ↔ 로봇 통신 | 누군가 명령을 보내 로봇을 움직임 | 분리된 네트워크, 방화벽, 인증 |
| 웹캠 스트림 | 영상 엿보기 | 외부 공개 금지, 기본 비밀번호 변경 |
| 학습 데이터(CSV) | 조작하면 잘못된 예측 | 접근 권한, 백업, 이상값 검사 |
| Python 패키지 | 악성 패키지 설치 | 공식 저장소, 버전 고정(requirements.txt) |
| GitHub 저장소 | 비밀번호·키 유출 | `.gitignore`, 토큰을 코드에 쓰지 않기 |

## 공부 순서

1. 네트워크 기초: IP, 포트, TCP/UDP, HTTP
2. 내 PC에서 `netstat` / `ss` 로 열린 포트 확인
3. Wireshark 로 **내** 로봇 제어 통신 패킷 관찰 (평문으로 보이는지 확인)
4. 인증·암호화: 비밀번호 해시, HTTPS, SSH 키
5. 합법 연습장: TryHackMe, HackTheBox, OverTheWire, Dreamhack
