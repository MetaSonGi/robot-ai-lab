관절 속도로 이동 시간 계산하기

관절이 일정한 속도로 돈다고 보면 시간은 각도를 속도로 나눈 값입니다. 실제 모터는 가속하고 감속하기 때문에 속도 그래프가 사다리꼴이 되고, 그만큼 시간이 더 걸립니다.

단순식 T = 각도 / v 90° / 30°/s = 3.0 s 사다리꼴 T = 각도 / v + v / a (각도 ≥ v²/a 일 때) 삼각형 T = 2 · √(각도 / a) (최고속도에 못 닿을 때)

Lesson 2simulate_data.py · train_model.py

AI로 예측 오차 줄이기

계산식은 이상적인 로봇을 가정합니다. 실제 로봇은 무거운 물건을 들면 가속이 덜 되고, 빠르게 멈추면 진동이 잦아들 때까지 기다리고, 통신 지연도 있습니다. 측정 데이터를 모아 회귀 모델이 이 차이를 학습하게 합니다. 물리 계산값을 버리지 않고 입력 특징으로 넣는 것이 핵심입니다.

입력: 이론시간, 속도%, 무게, 총 이동각, 구간 수 (+ 특징 공학: 속도², 이론시간×무게×속도) 출력: 실제 작업 시간

가상 측정 데이터로 학습

학습 75% · 평가 25%

왼쪽: 평균 절대 오차(MAE, 초). 오른쪽: 점이 대각선에 가까울수록 정확합니다. 회색은 이론값, 주황색은 특징 공학 회귀 모델입니다.

실습 과제

  1. 작업 수를 40개로 줄이면 어떤 모델이 더 흔들리나요?
  2. train_model.py 에서 add_features 를 빼고 랜덤포레스트와 비교해 보세요.
Lesson 3robot_time/rl_speed.py

강화학습으로 무게별 최적 속도 찾기

빠르면 시간이 줄지만 물건을 떨어뜨릴 수 있습니다. 로봇이 여러 번 시도하면서 보상(빠를수록 좋고, 떨어뜨리면 벌점)을 받아 무게마다 가장 좋은 속도를 스스로 찾습니다.

상태: 무게 구간 행동: 속도 30/50/70/90% 보상: −작업시간 − (떨어뜨리면 벌점) Q[상태][행동] ← Q + α · (보상 − Q) ε 확률로 무작위 탐험
학습한 시도0

표의 값은 평균 보상(대략 −초)입니다. ★ 가 학습된 최적 속도입니다. 아래 곡선은 최근 200회 평균 보상이 올라가는 모습입니다.

실습 과제

  1. 벌점을 0으로 하면 어떤 속도를 고르나요? 30으로 올리면?
  2. ε 을 0으로 두면 왜 학습이 잘못될 수 있는지 설명해 보세요.
Lesson 4lessons/04-vla.md

VLA: 보고, 듣고, 움직이는 로봇

VLA(Vision-Language-Action)는 카메라 영상과 "빨간 컵을 상자에 넣어" 같은 문장을 받아 로봇 행동을 만드는 모델입니다. 앞에서 만든 시간 예측과 속도 최적화는 VLA 뒤에 붙는 모듈이 됩니다.

입력카메라 영상 + 명령 문장
→
VLA무엇을 어디로 옮길지, 관절 목표 생성
→
Lesson 1·2이 동작이 몇 초 걸릴지 예측
→
Lesson 3무게에 맞는 속도 선택
→
출력로봇 실행 + "약 7초 걸립니다"

배우는 순서

  1. 모방학습: 티칭한 동작(관찰 → 행동 쌍)을 그대로 따라 하도록 학습
  2. 이미지 인식: 카메라로 물건 위치 찾기
  3. 언어 조건: 명령 문장에 따라 다른 행동
  4. 공개 VLA(OpenVLA, LeRobot 등)를 시뮬레이터에서 실행
Lesson 5mediaart/calibrate.py · draw_light.py

웹캠 + 빔프로젝터 빛 그리기

웹캠으로 움직임을 찾고, 그 위치에 빛의 궤적을 남겨 빔프로젝터로 벽에 투사합니다. 아래 무대에서 마우스나 손가락으로 그려 보세요. GitHub Pages 주소로 열면 웹캠 모드도 동작합니다.

마우스 / 터치로 그리기

움직임 추적 (OpenCV와 같은 순서)

컬러 → 흑백 → 블러 → 이전 프레임과 차이 → 이진화 → 흰 픽셀의 무게중심 = 손 위치

좌표 맞추기: 호모그래피

웹캠은 벽을 비스듬히 보기 때문에 카메라 좌표와 프로젝터 좌표가 다릅니다. 벽이 평평하면 3×3 행렬 하나로 바꿀 수 있습니다. calibrate.py 가 프로젝터에 원 4개를 띄우고, 카메라 화면에서 그 원을 클릭하면 행렬을 저장합니다.

H = cv2.getPerspectiveTransform(카메라_4점, 프로젝터_4점) 프로젝터좌표 = cv2.perspectiveTransform(카메라좌표, H)

입체 물체 표면까지 정확히 맞추려면 구조광 같은 3D 복원이 따로 필요합니다. 호모그래피는 평면 전용입니다.
